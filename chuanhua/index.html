DELIVERABLE / 提交标准

完整端到端 Agent 产品

Hackathon 结束时提交，评审周据此评估：

  • 明确的目标用户与使用场景
  • 可运行应用或线上访问链接
  • 完整的输入到输出工作流
  • 至少一个实质集成（工具 / API / 数据）
  • 能执行任务的 Agent，而非仅聊天界面
  • 基本异常处理与失败恢复
  • 代码仓库与开发过程记录
  • 简版架构图与技术说明
  • 已知限制与安全边界说明
直接拒绝：仅 PPT、纯概念、不可运行界面稿、预录演示、无实质任务执行链路的聊天套壳。
